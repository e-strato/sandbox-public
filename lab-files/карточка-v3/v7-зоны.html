v7 · Зоны

Карта собрана из чётких областей, у каждого блока своя зона: фото, рейтинг, герои, имя, роль, статы, команда. Ничего не наезжает, каждую зону можно править отдельно. Команда занимает всю нижнюю зону, без пилюли. Форма — один скос справа снизу. Шрифт один — Onest, обычной ширины. С Prism по всем зонам идёт перелив.
