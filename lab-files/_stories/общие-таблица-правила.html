Таблица — правила

Одна таблица на весь продукт: сайт и движок, компьютер, телефон и узкая колонка. Решено дирижёром 17.11 — лаба «(C) Таблицы на телефоне» v44, журнал — DECISIONS.md «17.11 — таблицы».
Новую таблицу не верстаем — собираем из частей ниже. Не хватает чего-то — добавляем в часть (новый вид слота, новое поле фильтра), а не пишем свою разметку.

1. Из чего собрана

Виджет (Widget, head="line")  ─  заголовок · подпись серым · [↺ Сбросить] [Фильтр]
└─ DataTable v4               ─  сортировка, группы, крест, фокус на группе, окно, телефон, состояния
   └─ Table v2                ─  рамка: плотность, полосы, прилипающая шапка, прокрутка
      ├─ HeadCell v2          ─  заголовок колонки / группы

TableFilter v2                ─  фильтр: попап (компьютер) / шторка (телефон)

Пример — «Игроки» (Общие/Таблица/DataTable v4), перепроверка — групповой этап, герои, команды (Общие/Таблица/Примеры).

2. Как собрать новую таблицу

const cols: Column<Row>[] = [
  { key: 'n',    label: '#',     width: 44,  pin: true, cell: (_r, i) => ({ main: { t: 'place', n: i + 1 }, align: 'center' }) },
  { key: 'team', label: 'Команда', width: 220, pin: true, sort: (r) => r.name,
    cell: (r) => ({ start: { t: 'logo', team: r.id }, main: { t: 'text', text: r.name, sub: r.region } }) },
  { key: 'wr',   label: 'WR', group: 'Карты', sort: (r) => r.wr, cell: (r) => ({ main: { t: 'pct', value: r.wr } }) },
]
<DataTable label="Команды" rows={rows} rowKey={(r) => r.id} columns={cols} sortValue={sort} onSortChange={setSort} />
  • Колонка = ключ, подпись, группа (если колонок больше 6), ширина, сортировка, ячейка из слотов.
  • pin: true — закреплена слева и видна на телефоне всегда: место «#» и «кто». Больше двух закреплённых — нельзя.
  • Сортировка по умолчанию — одна, самая осмысленная (KDA, пик + бан, место). «Сбросить» возвращает к ней.

3. Ячейка — три слота

СлотЧто можноКак ведёт себя
Левый startместо · лого 26 · лого турнира tlogo · фото · герой · позиция · флагне сжимается
Центральный main — обязателентекст (+ подпись) · число · процент · счёт · изменение · форма · плашка · участники лого logos (наведение — имя, больше max — «+N») · «—»сжимается, длинное — многоточием
Правый endпозиция · плашка · изменение · флагприжат вправо
  • Есть левый слот или текст — ячейка влево (это «кто», первая колонка). Иначе — по центру колонки. По правому краю — нет.
  • Высота строки 44 (плотная 34, просторная 52) — одна на таблицу. Поля 8, у края таблицы 16, на телефоне 12. Зазор между слотами 10.
  • Числа 13, серым, одной ширины. Главная цифра строки (KDA, всего) — тот же кегль, белая и жирная. Крупнее — нельзя. Одна главная на таблицу.
  • Числа: тысячи — 44,2k, дробь — запятой 6,1, процент — целым 69%, разница — со знаком +6.
  • Процент — плашкой: ≥ 60 зелёная, < 40 красная, между — без цвета.
  • Герой — квадратной иконкой 20, не широким портретом. Позиция — значком (с подсказкой роли), не цифрой. Место — отдельной колонкой «#», 1–3 в кружке.
  • Нет данных — «—» серым. Не 0 и не выдуманное.
  • Строка ведёт на страницу (турнир, матч) — onRowClick у DataTable / TableWidget: вся строка нажимается, Enter с клавиатуры.
  • Форма — { t: 'form', res, of: 5 }: всегда 5 ячеек, нет матча — прочерк (начальник 16.11).
  • Метка строки — одна плашка badge в правом слоте «кто»: игрок — «Замена» / «Стендин» / «New», команда — «i» (заметки); подробности — в подсказке плашки («Участники», 18.11).
  • Что куда ставить — «Ячейка → Слоты», готовые сборки — «Сборки», собрать самому — «Конструктор».

4. Заголовок

  • 11, серым, по центру (у «кто» — влево). Нажимается вся ячейка заголовка.
  • Сортировка: стрелка за подписью, место под неё заложено — подпись не прыгает. У активной колонки стрелка видна, подпись белая и жирная; при наведении на колонку — бледная стрелка. Повторное нажатие — обратно.
  • Колонка сортировки — без подложки.
  • Группа колонок — плашкой над её колонками. Вертикальных линий между группами нет.
  • Шапка прилипает при прокрутке и всегда непрозрачная.

5. Строка

  • Полосы через одну (2,5 %), линий между строками нет, полос слева нет.
  • Наведение — крестом: строка 8 %, колонка 6 %, ячейка на пересечении 14 %.
  • Навели на группу — фокус: остальные колонки тише (30 %), в шапке тише только текст.
  • Выбранная («моё») — фиолетовым фоном. Приглушённая (выбыл) — 50 %.

6. Высота

  • Компьютер — окно в 10 строк, остальное — прокруткой внутри. Отфильтровали — высота та же, страница не прыгает. Снизу «Всего N · прокрути таблицу» / «Найдено N из M».
  • Телефон и узкая колонка — без окна: таблица растёт вниз, «Показать ещё 10 · осталось N».

7. Телефон и узкая колонка

  • Одно правило: контейнер уже 640 px — телефонная подача. Это и телефон, и правая колонка 320 — включается само, по ширине.
  • Видны «#» и «кто» + колонки одной группы. Группы — сегментами под шапкой (раскрытие строки — не используем).
  • Сегменты одной ширины — по самой длинной подписи, в одну строку. Не влезают — прокрутка вбок, нажатый сам едет к центру.
  • Колонку можно спрятать на телефоне — phoneHide (например, «±»); ширина на телефоне — phoneWidth (по умолчанию 52).
  • Поля в ячейках — 4 (у края таблицы 12): колонки плотнее, справа нет пустоты.
  • Не помещается имя в «кто» (уже ~96 px) — остаётся только логотип / картинка левого слота.

8. Шапка виджета, фильтр, «Сбросить»

  • Заголовок, подпись серым (на телефоне подписи нет), справа ↺ Сбросить значком и Фильтр, обе высотой 32.
  • Сбросить возвращает сортировку и фильтр по умолчанию; всё и так по умолчанию — неактивна.
  • Фильтр по умолчанию спрятан. Компьютер — попап под кнопкой (Esc и клик мимо закрывают), телефон — шторка снизу.
  • Полей 2–3 (у игроков — позиция и команда). Низ: «Сбросить» · «Показать N».
  • Вид таблицы (например, «Составы / По позиции» у «Участников») — тоже поле фильтра, сегментом; пункт «ничего не выбрано» переименовывается allLabel.
  • Выбрано — числом кружком поверх угла кнопки, как уведомление в iOS. Пилюль под шапкой нет.
  • Таблица до ~100 строк, где фильтровать нечего, — без кнопки «Фильтр», только «Сбросить».

9а. Зоны (выход / вылет)

Решено дирижёром 17.11 — лаба «(C) Таблицы: зоны и шахматка» v9, части — «Общие/Таблица/Зоны · новые части».

  • Тон зоны — у всей строки: <Row tone="up | down"> — слабый фон 5 % зелёного / красного; полос через одну у таких строк нет. Ячейки фон не повторяют.
  • Место в строке зоны — кружок цвета зоны у всех мест (не только 1–3); вне строки — { t: 'place', n, tone }.
  • Между зонами — <RowDivider span label />: чёрная плашка 32, внутренний бордер 1px цвета разделителя сверху и снизу, подпись 12 по центру («↑ Плей-офф ↓ Выбыли»). Строк не перекрывает.
  • Разделитель — только в порядке мест; отсортировали иначе — пропадает.
  • В DataTable: rowTone={(r) => 'up' | 'down'} и zones={[{ after: N, label }]} (TableWidget — zones={{ rowTone, zones }}).

9б. Шахматка

CrossTable — круговая система «команда × команда» («Общие/Таблица/Шахматка»). Только из частей таблицы:
заголовок колонки — <HeadCell logo={team} /> · клетка — { t: 'score', a, b } плиткой во всю клетку (победа зелёная, поражение красная, ничья без цвета) · по диагонали — { t: 'self', team } (лого бледно) · не играли — { t: 'empty' } · справа итоги (extra) · зоны — pass.
Лого везде 26 — в «кто», в заголовке, по диагонали. Телефон — в «кто» только лого, клетки 44.
